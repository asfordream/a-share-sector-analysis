# A 股板块深度分析系统

一套面向 **11 个 A 股主题板块**的每日自动化深度分析流水线：采集行情 → 计算量能 → 渲染独立 HTML 报告 → 推送飞书 → 产出自选股候选与信号跟踪表。

代码为**投研内部工具**，非通用产品。数据源依赖 westock（腾讯自选股）CLI 接口，运行前需自行配置。

---

## 一、系统架构

```
        ┌─────────────────────────────────────────────────────────────┐
        │  M1 collect      采集 11 板块 × Top40 成分（按流通市值）      │
        │      ↓           行情 / 均线 / 技术指标 / 量比                │
        │  M2 swing        量能评分（缩量 50 + 放量 50）→ 强/中/弱      │
        │      ↓           写回 volGrade / volScore / swingLow         │
        │  M3 charts       生成板块指数 + PEERS 对比图表数据            │
        │      ↓                                                       │
        │  M4 render       渲染 11 份独立 HTML 报告                    │
        │      ↓           + _summary.json（cands / mups / 裁决）      │
        │  M5 tech4        四层体检 + 评级×技术面三步裁决（引擎）       │
        │      ↓                                                       │
        │  M6 push_bot_md  飞书 bot 上传 HTML + 日报/链接消息          │
        │  M7 push_webhook 飞书群自定义机器人卡片推送                   │
        │      ↓                                                       │
        │  M8 watchlist    自选股候选（裁决=🔴 的板块）→ 写入分组       │
        │  M9 track_table  信号跟踪表（回抽确认 / 主升浪买点区双子表）   │
        └─────────────────────────────────────────────────────────────┘
                          ┌──────────────────────┐
                          │ M10 watchdog 独立看门狗 │ 每日校验产物齐备性
                          │ M11 verify   信号回溯   │ 历史有效性验证
                          └──────────────────────┘
```

**关键约束**：`M2 swing` 不可省略。缺少该步会导致 `volGrade` 为空，回抽/主升浪候选被全部过滤为 0。

## 四、快速开始

### 1. 配置凭据

代码内**不含任何真实凭据**，全部通过环境变量注入。复制模板后填入自己的值：

```bash
cp .env.example .env
# 编辑 .env，填入飞书 webhook / open_id / 群 chat_id 等
set -a && source .env && set +a
```

`lark-cli` 需单独安装，默认从 `PATH` 查找，也可用 `LARK_CLI` 指定绝对路径。

### 2. 按顺序运行

```bash
python3 scripts/collect.py                       # M1
python3 scripts/swing.py                         # M2（必需，不可跳过）
python3 scripts/charts.py                        # M3
python3 scripts/render.py                        # M4
python3 scripts/push_bot_md.py                   # M6
python3 scripts/push_webhook.py --links          # M7
python3 scripts/build_watchlist.py               # M8
python3 scripts/build_track_table.py             # M9
```

**运行后必须校验**：`collect.py` 输出的「缺 MA20」计数应为 0。技术面采集按 25 只/批分块，首块偶发超时会导致整块落空，此时需重跑。

### 3. 产物

| 产物 | 说明 |
|---|---|
| `data/<板块>.json` | 板块成分行情+技术面，每板块一份 |
| `data/_summary.json` | 汇总候选（`cands` / `mups`），下游 M8/M9 的唯一输入 |
| `<板块>板块深度分析_<YYYYMMDD>.html` | 每板块独立报告，**严禁合并** |
| `A股板块候选跟踪表.xlsx` | 信号跟踪表（双子表 + 归档表） |

## 五、核心规则速览

### 选股漏斗

| 层级 | 条件 |
|---|---|
| L1 | 流通市值 Top40 |
| L2 | 量能等级 强 / 中（弱直接剔除） |
| L3 | MA20 距离 0 ~ −10% |
| L4 | RSI6 ∈ [32, 64]，且**确认态 = 已确认** |

### 评级 × 技术面裁决

按 **「评级定方向、技术面定节奏、量能扣扳机」** 三步裁决：① 产业逻辑是否证伪 → ② 是否跌破 MA60 且 MACD 翻绿（安全阀）→ ③ 结构与量能强弱。技术面只调执行强度、不改评级，**唯一例外是破位**。

### 跟踪表状态机（目标阶梯 6 档）

判定序：`已破位`（≤止损线）> `52周高位`（≥前高×0.95）> `逼近前高`（≥前高×0.85）> `第一目标`（≥目标1）> `上涨中` > `回调中`。

- **当前状态**：每日刷新，可升可降 —— 回答「今天在哪」
- **曾达档位**：只升不降 —— 回答「曾经到过哪」
- **首破位日**：写入一次即锁定 —— 回答「何时出过局」

滚动覆盖键 = **(板块, code)**，且**仅当今日产生新信号时**才覆盖旧行，旧行移入归档表并继承曾达档位。

## 六、数据源

- **westock**（腾讯自选股数据栈）：行情、均线、技术指标、量比、K 线
- 板块代码支持申万（`pt018xxxxx`）与聚源概念（`pt02GNxxxx` / `pt020xxxxx`）

数据源不可用时，相关字段标 `[MISSING]`，**不做估算填充**。
