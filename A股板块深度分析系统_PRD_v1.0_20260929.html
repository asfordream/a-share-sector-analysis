1产品概述

1.1 一句话定位

把「一个 A 股板块到底该不该买、现在买还是等回踩、以及买哪几只」这三件靠人肉翻数据的事，固化成一条每日自动跑、结论可直接执行、且留痕可回测的生产线。

1.2 用户与使用场景

用户场景期望拿到什么
吉总
（投研 / 兼 PM）		 收盘后 15:15手机飞书收到 11 板块日报卡片：每板块一句裁决 + 四层体检 + 可执行个股名单
想看深逻辑点链接打开该板块 10 节深度 HTML（产业链/景气/多空/催化剂/PM七问）
要下自选股当日「裁决 🔴」板块的已确认候选，自动写进腾讯自选股当日期分组
做调优复盘候选跟踪表逐行留痕（当前状态/曾达档位/首破位日）+ 离线事件研究回测

1.3 解决什么问题（痛点 → 做法）

原始痛点本系统的做法落地位置
人工判断「技术面偏弱」太笼统拆成四层可判定体检（动能/结构/量能/位置），每层给指标 + 阈值 + 颜色M5 tech4.py
评级与技术面打架时不知听谁固化三步裁决 + 四组决策树：评级定方向、技术面定节奏、量能扣扳机；唯一例外是破位M5 _verdict()
「看到候选但错过买点」候选落成带价位的跟踪表（买点区间/止损/目标1/目标2），每日刷新状态M9
判断出主升浪但实际没涨两次收紧确认口径（2026-09-02），加"真实 thrust"硬门槛；宁可少给也不给假信号M4 / M5
「今天到底跑没跑」无从判断独立看门狗按文件系统事实巡检 4 项产物，异常才告警M10

1.4 边界（明确不做的事）

  • 不预测股价、不给买卖评级。输出的是「技术面状态 + 与人工评级的匹配度 + 价位参考」；方向仍由人工评级（narratives.json）决定。
  • 不做基本面建模。财务/估值只做展示（PE/PB/市值），不做 DCF、不做盈利预测。
  • 本文件只覆盖 A 股。港美股另有 hk-sector/、us-sector/ 两套同源脚本（HK/US 无 Step G/H）。
  • 不自动交易。只写自选股分组，不下单。
  • 不臆造数据。取不到就标 [MISSING] 或留空，绝不用估算填充。

4模块详述

M1collect.py —— 数据采集 scripts/collect.py · 188 行 · 1'47" ~ 13'44"
职责
把每个板块从「一个指数代码」变成「40 只成分股 × 完整行情技术字段」的结构化 JSON。
入口
python3 scripts/collect.py [板块名 ...]（不传参 = 全 11 板块）

处理流程（6 步）

  1. 板块自身行情：quote <板块代码>；PCB 例外 —— 走 INDEX_OVERRIDE 换成 PCB 概念指数 pt02101284（申万三级指数盘中不跳动）。
  2. 取成分股：sector constituent <code> --limit 220。过滤规则：代码为空 → 剔除；名称含 ST → 剔除；北交所 bj 前缀 → 剔除（流动性差）。
  3. 批量行情：quote 每批 40 只，批间 sleep 0.4s。
  4. 排序取 Top40：按 circulating_market_cap（流通市值）降序取前 40。universe 口径的关键决策
  5. 技术指标：technical --group ma,macd,rsi，每批 25 只。
  6. 组装 universe：算 distMa*、qbUptrend；swingLow 等先置 None（交给 M2）。
踩坑：技术面 25/批，首块偶发超时整块落空 会静默产生一批 ma20=None 的个股 → 下游出现「站上MA20 0/40」的假读数。每次跑完必须校验「该板块缺 MA20 的只数 == 0」，否则单独重跑该板块。
口径说明：为什么取 Top40 而不是全成分 PCB 全成分 46 只、半导体 365 只。取流通市值 Top40 让「板块代表股」稳定可比，代价是小市值弹性股会被挤出（元件「独有 9 只全是被动元件」的假象正是这个机制造成的）。
M2swing.py / swing_fill.py —— 量能评分与波段位 169 / 154 行 · 41"
职责
为每只成分算 volScore / volGrade（量能三档）、swingLow / swingHigh / reboundPct / ddFromHigh，写回 data/<板块>.json。
关键性
链路必经 缺这一步 → volGrade 为空 → 回抽确认与主升浪候选被量能硬门槛全部过滤为 0（2026-08-12 实害）。

量能评分算法（0-100 = 缩量分 50 + 放量分 50）

分量定义给分档位
缩量比 shrink近 5 个完整交易日均量 ÷ 20 日均量≤0.5 → +50 ｜ ≤0.8 → +30 ｜ ≤1.0 → +15 ｜ >1.0 → 0
放量比 expand盘中：取 volRatio（量比，时间归一化）
收盘：当日量 ÷ 近5日均量		≥1.2 → +50 ｜ ≥1.0 → +30 ｜ ≥0.8 → +15 ｜ <0.8 → 0

分级：强 ≥75 中 40~74 弱 <40

动机
跟踪表原「状态」列按当日快照价机械判定、没有路径概念（不记录是否曾触及止损、不区分先止损还是先止盈）→ 不能当成败依据。故改用日K线做真正的事件研究。
方法
Event Study。入场：信号日收盘落在买点区 → 按收盘入场；否则次日起首个「日内触及买点区」的日子按区间挂单成交（价 = clamp(open, lo, hi)）；开盘即跌破下限判「跳空破位，信号失效」不入场。
出场：逐日推进，触及止损按 min(open, stop) 成交（跳空低开更差，贴合实际）；触及目标按目标价成交；同日既触止损又触目标 → 保守计止损并单独披露。
